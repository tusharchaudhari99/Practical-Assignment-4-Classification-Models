# Practical-Assignment-4-Classification-Models
Rice classification using SVM, KNN, Decision Tree, and Naïve Bayes with Python, Scikit-learn, data preprocessing, model evaluation, and confusion matrices.

## 1. Introduction

This practical assignment focuses on developing and evaluating machine learning classification models using Python. The Rice Classification dataset is used to train different supervised learning algorithms and compare their performance.

The main aim is to identify the most suitable classification algorithm based on evaluation metrics such as accuracy, precision, recall, F1-score, and log loss.

## 2. Objectives

- Understand the working of supervised classification algorithms.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Train and test different classification models.
- Tune model hyperparameters to improve performance.
- Evaluate models using confusion matrices and performance metrics.
- Compare the algorithms and identify the best-performing model.

## 3. Dataset Description

The project uses the Rice Classification dataset, which contains numerical features describing rice samples and a target class used for classification.

**Dataset file:** `riceClassification(2).csv`

The dataset is processed before model training to check missing values, remove duplicate records, select input features, and prepare the target labels.

## 4. Algorithms Used

### 4.1 Support Vector Machine (SVM)

SVM is a supervised machine learning algorithm that finds an optimal decision boundary, called a hyperplane, to separate different classes. It aims to maximize the margin between classes. In this project, SVM is trained using feature scaling and hyperparameter tuning.

### 4.2 K-Nearest Neighbors (KNN)

KNN classifies a sample based on the classes of its nearest neighboring samples. The model uses feature scaling and hyperparameter tuning to select suitable parameters, including the number of neighbors and distance metric.

### 4.3 Decision Tree

A Decision Tree classifies samples through a series of decision rules based on feature values. It is easy to interpret and can be visualized as a tree structure.

### 4.4 Naïve Bayes

Naïve Bayes is a probabilistic classification algorithm based on Bayes' theorem. Gaussian Naïve Bayes is used for the numerical features in this dataset.

## 7. Evaluation Metrics

- **Accuracy:** Measures the proportion of correctly classified samples.
- **Precision:** Measures the proportion of predicted positive samples that are correct.
- **Recall:** Measures how many actual positive samples are correctly identified.
- **F1-score:** Combines precision and recall into a single metric.
- **Log Loss:** Measures the difference between predicted probabilities and actual class labels.
- **Confusion Matrix:** Shows correct and incorrect predictions for each class.
- **Cross-validation:** Evaluates model performance across multiple data splits.
